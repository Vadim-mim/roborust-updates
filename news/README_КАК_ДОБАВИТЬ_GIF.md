# Новости RoboRust — JPG, PNG и GIF

## Как добавить GIF

1. Подготовь GIF-файл, например `new-map.gif`.
2. Загрузи его в репозиторий в папку `news/images`.
3. Открой `news/news.json`.
4. В поле `imageUrl` укажи прямую raw-ссылку на GIF.
5. Поля `videoUrl` и `buttonText` можно оставить пустыми.
6. В лаунчере нажми `Новости` → `Обновить новости`.

Пример:

```json
{
  "id": "new-map-animation",
  "title": "Новая карта в движении",
  "date": "31.07.2026",
  "text": "Короткая демонстрация новой локации прямо в лаунчере.",
  "imageUrl": "https://raw.githubusercontent.com/Vadim-mim/roborust-updates/main/news/images/new-map.gif",
  "videoUrl": "",
  "buttonText": ""
}
```

## Важно

- Используй новое уникальное имя файла для каждой новой GIF.
- Рекомендуемый размер: `640×360` или `960×540`.
- Желательно: до 10 МБ и до 10–15 секунд.
- Лаунчер принимает GIF до 25 МБ, но слишком большие анимации используют много памяти.
- Кнопка `Обновить новости` принудительно перекачивает изображения и GIF из GitHub.
- Обычные JPG, PNG и ссылки на видео продолжают работать.

В папке `images` находится тестовая `example-animation.gif`, а рядом — готовый пример `news-gif-example.json`.
